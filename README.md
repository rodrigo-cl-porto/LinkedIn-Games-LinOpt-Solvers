# 🎮 Solving LinkedIn Games by Linear Optimization

This repository of contains the project for my Jupyter Book in which I present examples on how to solve LinkedIn games by using Python libraries, such as Pyomo, for mathematical modeling, and NetworkX, for modeling the game board as a graph.
